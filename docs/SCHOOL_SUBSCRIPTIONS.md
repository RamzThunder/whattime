# 학교 특별시정 구독과 게시

별도 서버 없이 공개 GitHub 저장소의 `schedules.json`을 게시 원본으로 사용합니다.
사용자 앱은 `RamzThunder/whattime-releases` 저장소의 `main` 브랜치에 있는 `schedules.json`만 구독합니다.
시정 데이터와 앱 설치 파일은 별도로 갱신하므로, 이후 시정 변경마다 앱을 배포할 필요는 없습니다.
단, 구독 기능이 없는 기존 앱은 이 기능을 포함한 버전으로 먼저 업데이트해야 합니다.

## 관리자 최초 설정

1. GitHub에서 `RamzThunder/whattime-releases`에 접근할 수 있는 fine-grained personal access token을 만듭니다.
   Repository access는 이 저장소만, Repository permissions의 **Contents는 Read and write**로 설정합니다.
   저장소는 공개 상태여야 하고, `main` 브랜치가 있어야 합니다. 사용자 앱의 구독 주소는 고정되어 있습니다.
2. 관리자 앱을 실행합니다. 개발 환경에서는 `python3 schedule_admin.py`로 실행할 수 있습니다.
   필요한 패키지는 `python3 -m pip install pywebview certifi keyring olefile==0.47`으로 설치합니다.
3. 토큰을 관리자 화면의 암호 입력란에 입력하고 **게시 내용 불러오기**를 누릅니다.
   **토큰 저장**을 누르면 macOS 키체인 또는 Windows 자격 증명 저장소에 보관하고, 다음 실행부터 자동으로 사용합니다. **저장 삭제**로 지울 수 있습니다. 저장하지 않고 직접 입력해서 사용할 수도 있습니다. 시정 파일이나 사용자 앱에는 토큰을 넣지 않습니다.
4. 파일이 아직 없으면 빈 학교 목록에서 시작합니다. **학교 추가**로 고유한 학교 ID와 이름을 입력합니다.
   ID는 학교 이름이 바뀌어도 유지하세요. 앱은 이 ID로 학교를 구독합니다.

API 권한과 파일 갱신 방식은 [GitHub Contents API 문서](https://docs.github.com/en/rest/repos/contents)를 따릅니다.
게시 토큰을 채팅이나 공개 저장소에 올리지 마세요.

## 시정 게시·수정·취소

1. 학교를 선택하고 **날짜 추가**를 누릅니다.
2. 날짜와 제목, 교시별 이름·시작·종료 시각을 입력합니다.
   직접 작성할 때 첫 행은 **아침활동 및 학급조회**, 시작은 **08:20**으로 고정됩니다. 종료 기본값은 08:40이며 변경할 수 있습니다.
   두 번째 행은 1교시부터 시작합니다. 직접 작성한 시간표를 편집할 때 아침활동 행이 없으면 앞에 추가합니다. 문서에서 불러온 시간표는 이 규칙을 적용하지 않습니다.
   시각은 **24시간제 HH:MM**으로 입력합니다(예: 08:20, 13:20). `820`이나 `1320`은 칸을 벗어날 때 자동으로 정리합니다.
   같은 날 안의 시정만 지원하며 시각이 겹치거나 같은 학교에 날짜가 중복되면 게시할 수 없습니다.
   개인 시간표를 연결할 교시는 기존 앱과 동일하게 `1교시`, `2교시` 등으로 이름을 붙이세요.
   `다른 날짜로 복사`로 같은 시정을 여러 날짜에 등록할 수 있습니다.
3. **변경 내용 확인 · 게시**에서 공개될 전체 시정과 삭제할 학교·날짜를 검토합니다.
4. **GitHub에 게시**를 누르면 시정 파일 하나를 커밋합니다.
5. 수정할 때는 게시 내용을 다시 불러온 뒤 편집합니다. 날짜를 삭제하고 게시하면 그 날짜의 특별시정이 취소됩니다.

다른 곳에서 파일을 수정했다면 GitHub의 파일 SHA 충돌 검사로 덮어쓰기를 막습니다.
충돌 시에는 다시 불러온 다음 수정해야 합니다. 아직 게시하지 않은 편집 내용은 파일로 보관되지 않습니다.
파일을 직접 지우면 앱은 수신 실패로 보고 기존 시정을 유지하므로, 취소하려면 관리 도구에서 날짜를 삭제해 게시하세요.

현재 학교 목록과 시정을 파일 하나에 담으며 게시 크기는 500KB로 제한합니다.
학교 ID·이름·날짜·시정은 공개됩니다. 개인 시간표나 교사별 데이터는 넣지 않습니다.
관리자 앱에서 게시한 내용의 GitHub 커밋 기록은 저장소에서 확인할 수 있습니다.

## 사용자 구독

1. **설정 → 일정 관리 → 학교 특별시정 구독**에서 **새로고침**을 누릅니다.
2. 학교를 고르고 **적용**을 누릅니다. 구독 변경은 즉시 저장됩니다.
3. 앱은 구독 중일 때 **시작 시 한 번** 새 파일을 확인합니다. 오늘 이후의 특별시정에 추가·수정·취소가 있으면 변경 내용을 보여주고 받아올지 물어봅니다. 승인한 경우에만 적용하며, 취소하면 기존 시정을 유지합니다. 실행 중 주기적으로 확인하지 않습니다. 설정에서 수동 새로고침도 가능합니다.
4. 오늘 적용 중인 학교와 특별시정 제목이 위젯에 표시됩니다.
5. 해제하려면 **구독 안 함 → 적용**을 누릅니다.

구독 기능은 `일정 관리 > 특별 시정`의 수동 특별시정 사용 스위치와 독립적으로 동작합니다.
적용 우선순위는 **직접 지정한 특별시정 → 구독한 학교 특별시정 → 쉬는 날/일반 시정**입니다.
토요일 행사도 날짜가 지정되어 있으면 적용합니다. 등록되지 않은 날짜는 기존 설정을 사용합니다.
일반 시정, 개인 시간표, 디자인 설정은 구독으로 덮어쓰지 않습니다.
구독 시정의 교시는 일반 시정의 교시 번호 또는 동일한 이름으로 개인 시간표와 연결합니다.
예를 들어 게시 시정에 아침 일정이 생략되어 있어도 1교시에 연결된 과목이 밀리지 않습니다.

## 연결 실패와 저장

- 사용자가 승인한 파일과 구독 학교는 앱 데이터 폴더의 `school_subscription.json`에 별도로 저장합니다. 확인용으로 가져온 변경 내용은 승인 전에는 현재 시정에 적용하거나 파일에 저장하지 않습니다.
- 인터넷 연결 실패, 잘못된 게시 파일, 일시적인 GitHub 오류가 발생하면 마지막 정상 시정을 계속 사용합니다.
- 게시자의 취소·수정도 사용자가 새 파일 수신을 승인해야 반영됩니다. 인터넷이 끊긴 기기에는 즉시 전파되지 않습니다.
- 설정 화면에서 마지막으로 적용한 파일의 수신 시각과 최근 오류를 확인할 수 있습니다. 변경이 없거나 지난 날짜만 바뀌었다면 별도 질문 없이 목록 정보를 갱신합니다.
- 거절한 변경은 다음 앱 시작 또는 수동 새로고침 때 다시 제안합니다.
- GitHub 캐시와 네트워크 상태에 따라 게시 직후 수동 새로고침에도 이전 내용이 보일 수 있습니다.
- 사용자 화면에는 구독 주소 설정이 없으며 지정된 원본 파일만 읽습니다. 이전에 다른 주소를 사용한 캐시는 적용하지 않습니다.
- 기존 전체 설정 백업·복원과 초기화는 구독을 변경하지 않습니다. 구독은 해당 영역에서 별도로 해제하세요.
- 서버를 따로 운영하지 않지만 공개 GitHub 파일 제공 서비스에 의존합니다.

## 개발 및 빌드

```sh
python3 -m unittest discover -s tests -v
node tests/test_subscription_widget.js
node tests/test_admin_editor.js
python3 -m PyInstaller schedule_admin.spec
```

관리자 빌드 결과는 macOS의 `dist/특별시정 관리자.app`, Windows의 `dist/WhatTime-Schedule-Admin.exe`입니다.
GitHub Actions의 기존 빌드 작업에서도 관리자 프로그램을 별도 artifact로 만듭니다.
일반 사용자 릴리즈에는 관리자 프로그램을 자동으로 추가하지 않습니다.

시정 파일 형식 예시(실제 게시 데이터가 아닙니다):

```json
{
  "version": 1,
  "schools": [
    {
      "id": "example-school",
      "name": "예시학교",
      "events": [
        {
          "date": "2026-10-15",
          "title": "단축시정",
          "periods": [
            {"name": "1교시", "start": "09:00", "end": "09:40", "no_countdown": false},
            {"name": "2교시", "start": "09:50", "end": "10:30", "no_countdown": false}
          ]
        }
      ]
    }
  ]
}
```

## 한글 문서에서 시정 불러오기

관리자에서 학교와 적용 날짜를 선택하고 **HWP·HWPX에서 불러오기**를 누릅니다. 추출이 성공한 뒤 현재 시정을 교체할지 확인하며, 취소하거나 실패하면 편집 중인 시정을 유지합니다. 적용 날짜와 제목은 바꾸지 않습니다. 불러온 시정은 첫 행 이름·시작 시각도 수정하거나 삭제할 수 있고, 복사·게시·다시 불러온 뒤에도 첫 행 고정 규칙을 적용하지 않습니다. 직접 새로 작성하는 시정은 기존 08:20 아침활동 규칙을 유지합니다.

HWPX는 기존 앱과 같은 추출기를 사용합니다. HWP 5 문서는 별도 변환이나 한글 설치 없이 본문 표를 직접 읽습니다. 암호·배포용 문서, 구형 HWP, 이미지로만 된 표는 지원하지 않습니다. 이런 파일은 편집 가능한 HWPX로 저장해 다시 시도하세요. 여러 표가 있으면 추출 가능한 일정이 가장 많은 표를 선택하므로 게시 전에 교시명과 시각을 확인하세요. 파일은 로컬에서 읽으며, 문서 자체는 GitHub에 올리지 않습니다.

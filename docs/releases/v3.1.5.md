# 지금 몇교시야 3.1.5

macOS에서 진도 저장 직후 앱이 간헐적으로 꺼지던 문제에 대응한 패치입니다. Windows와 macOS 모두 배포합니다.

- **저장 결과 팝업이 바로 닫히던 문제를 고쳤습니다.** 쉬는 시간에는 "지난 진도" 팝업만 자동으로 닫히고, 저장 결과와 진도 기록 창은 직접 닫을 때까지 유지됩니다.
- **macOS: 앱이 예고 없이 멈추면 자동으로 다시 켜집니다.** ✕ 버튼이나 Dock의 종료로 끈 경우에는 다시 켜지지 않습니다.
- **macOS: 진단 로그를 남깁니다.** 진도 저장, 팝업 열고 닫기, 종료 경로가 `~/Library/Logs/WhatTime/whattime.log`에 기록됩니다. 앱이 또 꺼지면 이 파일을 보내 주세요.

꺼짐의 정확한 원인은 아직 확인 중입니다. 이번 버전의 로그로 원인을 확정할 예정입니다.

## 설치

- Windows: `whattime.exe`
- macOS: `WhatTime-mac.dmg`

기존 설정을 유지한 채 업데이트할 수 있습니다.

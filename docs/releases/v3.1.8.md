# 지금 몇교시야 3.1.8

컴시간알리미에서 시간표를 다시 불러오지 못하던 문제를 고친 패치입니다. Windows와 macOS 모두 배포합니다.

- **컴시간 불러오기가 다시 됩니다.** 2026년 11월 말 컴시간알리미가 요청 방식과 암호 형식을 바꾸고 페이지 속 이름을 무작위로 바꾸면서 학교 검색과 이번 주 시간표 불러오기가 실패하던 문제를 고쳤습니다.
- 이름이 또 바뀌어도 버틸 수 있도록 페이지 구조를 보고 필요한 값을 찾게 했습니다.
- 이미 저장한 학교코드와 교사 번호는 그대로 쓸 수 있어서 다시 설정할 필요가 없습니다.

## 설치

- Windows: `whattime.exe`
- macOS: `WhatTime-mac.dmg`

기존 설정을 유지한 채 업데이트할 수 있습니다.

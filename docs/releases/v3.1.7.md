# 지금 몇교시야 3.1.7

컴시간알리미에서 시간표를 다시 불러오지 못하던 문제를 고치고, 앱 아이콘을 새로 바꾼 패치입니다. Windows와 macOS 모두 배포합니다.

- **컴시간 불러오기가 다시 됩니다.** 2026년 11월 중순 컴시간알리미가 학교명·교사명·과목명 같은 글자 자료까지 따로 암호화하면서 학교 검색과 이번 주 시간표 불러오기가 실패하던 문제를 고쳤습니다.
- 이미 저장한 학교코드와 교사 번호는 그대로 쓸 수 있어서 다시 설정할 필요가 없습니다.
- **앱 아이콘이 바뀌었습니다.** 시계탑 학교와 시간표가 함께 있는 새 아이콘입니다.

## 설치

- Windows: `whattime.exe`
- macOS: `WhatTime-mac.dmg`

기존 설정을 유지한 채 업데이트할 수 있습니다.

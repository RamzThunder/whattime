# 지금 몇교시야 3.0.1

Windows에서 학교 특별시정 변경 확인창이 위젯 밖으로 잘려 버튼을 누르지 못하고 앱 조작이 막히던 문제를 수정했습니다.

- 기본 브라우저 확인창을 앱 내 확인창으로 교체했습니다.
- 작은 창과 미니 모드에서도 ‘나중에 / 받아오기’ 버튼이 보이며, 긴 변경 목록은 따로 스크롤할 수 있습니다.
- ‘나중에’ 또는 Esc를 누르면 기존 시정을 유지합니다. ‘받아오기’를 선택해야 변경 내용을 적용합니다.
- 설정 화면의 수동 새로고침에도 같은 수정을 적용했습니다.

기존 확인창에서 멈춘 경우 Esc로 취소한 뒤 업데이트하세요. 앱 조작이 불가능하면 앱을 종료하고 최신 설치 파일로 교체해 주세요. 기존 설정은 유지됩니다.

Windows: `whattime.exe` · macOS: `WhatTime-mac.dmg`

# 지금 몇교시야 3.1.0

특별시정의 교시 이름과 개인 수업을 따로 연결할 수 있게 한 업데이트입니다. ‘3학년 6교시 (1·2학년 급식)’처럼 이름이 바뀌거나 학년별로 시간이 나뉘어도 올바른 수업을 표시합니다.

## 특별시정 개인 수업 연결
- 직접 만든 특별시정과 학교 구독 시정의 각 행에 **연결할 기본 교시**와 **적용 학년**을 지정할 수 있습니다.
- 적용 학년은 그 교시에 배정된 반(예: `3-4`)의 학년을 기준으로 합니다. 해당 학년 반의 수업만 표시합니다.
- 교시 번호가 있는 이름은 자동으로 연결하며, 이름을 바꿔도 지정한 연결은 유지됩니다.

## 날짜별 개인 수업 조정
- 설정의 **특별 시정 → 날짜별 개인 수업 조정**에서 날짜를 골라 칸마다 기본 시간표 사용, 직접 입력, 수업 없음 중 선택할 수 있습니다.
- 학교 구독 시정의 연결도 그날만 바꿀 수 있으며, **이 칸 조정 해제**로 기본 연결로 되돌립니다.
- 위젯 표시, 진도 기록, 데스크탑 수업 이동 알림이 모두 같은 연결을 사용합니다.
- 컴시간 갱신은 특별시정 연결과 날짜별 직접 입력을 지우지 않습니다.

## 설치
- Windows: `whattime.exe`
- macOS: `WhatTime-mac.dmg`

기존 설정을 유지한 채 업데이트할 수 있습니다. 기존 특별시정은 교시 이름에서 연결을 자동으로 추정하므로, 교시 번호가 없는 행은 설정에서 연결 교시를 확인해 주세요.

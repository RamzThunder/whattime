# 지금 몇교시야 3.1.1 (Windows)

수업 시작 알림 팝업을 로드할 때 간헐적으로 응답 없음이 발생할 수 있는 경로를 수정했습니다.

- JavaScript API 초기화 중 네이티브 창 객체를 탐색하지 않도록 창 참조를 내부 속성으로 변경했습니다.
- 알림창과 다른 팝업창이 열려 있어도 API 초기화가 창 객체를 탐색하지 않는지 회귀 테스트를 추가했습니다.
- Python 테스트 64개와 JavaScript 테스트를 통과했습니다. Windows 실기기에서 간헐적 멈춤이 해결됐는지는 추가 확인이 필요합니다.

## 설치

Windows용 `whattime.exe`만 배포하는 패치입니다. 기존 설정을 유지한 채 실행 파일을 교체할 수 있습니다.

macOS는 이번 패치에서 새로 배포하지 않습니다. 기존 [3.1.0 릴리즈](https://github.com/RamzThunder/whattime-releases/releases/tag/v3.1.0)의 `WhatTime-mac.dmg`를 사용해 주세요.

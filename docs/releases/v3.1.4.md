# 지금 몇교시야 3.1.4

노션 주간 시간표 보관을 실험실로 옮긴 패치입니다. Windows와 macOS 모두 배포합니다.

- **노션에 주간 시간표 보관**이 설정 > 일정 관리 > 개인 시간표에서 설정 > 실험실로 옮겨졌습니다. 다른 실험 기능처럼 스위치로 켜고 끕니다.
- 보관 페이지 링크와 API 토큰은 스위치 아래 **노션 연결 설정**을 펼쳐서 입력합니다.
- 3.1.3에서 저장한 보관 설정과 토큰은 그대로 유지됩니다. 동작도 같습니다.

## 설치

- Windows: `whattime.exe`
- macOS: `WhatTime-mac.dmg`

기존 설정을 유지한 채 업데이트할 수 있습니다.

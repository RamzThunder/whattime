# 지금 몇교시야 3.0.0

학교 특별시정 구독과 수업 이동 알림을 추가한 메이저 업데이트입니다.

## 학교 특별시정 구독
- 학교를 선택하면 게시된 특별시정을 받아올 수 있습니다.
- 앱 시작 시 변경 사항이 있을 때만 받아올지 묻습니다. 사용자가 동의하면 적용합니다.
- 일반 시정과 개인 시간표를 유지하며, 인터넷 연결이 없어도 마지막으로 받은 시정을 사용합니다.

## 시간표 관리
- 매주 월요일 컴시간 알리미 시간표를 자동 갱신합니다. 컴시간 학교·교사를 먼저 설정해야 합니다.
- 급식지도 등 직접 입력한 개인 일정은 갱신해도 유지합니다.
- 특별 시정과 1학년 5교시 점심시간 배치를 정식 설정으로 옮겼습니다.

## 데스크탑 수업 이동 알림 (실험실)
- 개인 시간표에 반이 등록된 수업이 시작되면 이동할 반을 큰 창으로 알려줍니다.
- 시작 20초 이후 마우스·키보드 입력이 감지되면 더 큰 재알림을 한 번 표시합니다.
- 재알림의 ‘이번 시간 알림하지 않기’로 해당 수업만 끌 수 있습니다.
- 첫 알림과 재알림의 문구·색상·배경 사진·사진 어둡기를 꾸미고 미리보기로 확인할 수 있습니다.

## 설치
- Windows: `whattime.exe`
- macOS: `WhatTime-mac.dmg`

기존 설정을 유지한 채 업데이트할 수 있습니다. 새 수업 이동 알림은 기본으로 꺼져 있으며 실험실에서 켜고 저장하세요.
관리자 도구는 운영자용 별도 앱으로, 이번 사용자 릴리즈의 첨부 파일에는 포함하지 않습니다.

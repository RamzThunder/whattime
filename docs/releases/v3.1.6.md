# 지금 몇교시야 3.1.6

컴시간알리미에서 시간표를 불러오지 못하던 문제를 고친 패치입니다. Windows와 macOS 모두 배포합니다.

- **컴시간 불러오기가 다시 됩니다.** 2026년 11월 컴시간알리미가 접속 방식을 바꾸면서 "HTTP Error 403: Forbidden"이 뜨고 이번 주 시간표를 불러오지 못하던 문제를 고쳤습니다.
- **학교 검색도 새 방식에 맞췄습니다.** 이미 저장한 학교코드와 교사 번호는 그대로 쓸 수 있어서 다시 설정할 필요가 없습니다.
- 컴시간에 요청 횟수 제한이 생겨, 짧은 시간에 여러 번 불러오면 "1분 후 다시 시도해 주세요" 안내가 뜰 수 있습니다.

## 설치

- Windows: `whattime.exe`
- macOS: `WhatTime-mac.dmg`

기존 설정을 유지한 채 업데이트할 수 있습니다.

# 지금 몇교시야 3.1.3

컴시간 시간표를 노션에 주간 페이지로 쌓는 기능을 추가했습니다. Windows와 macOS 모두 배포합니다.

- 설정 > 일정 관리 > 개인 시간표에 **노션에 주간 시간표 보관**이 생겼습니다. 켜 두면 월요일 자동 갱신과 **이번 주 불러오기** 때마다 그 주의 개인 시간표가 노션 페이지로 만들어집니다.
- 주마다 `수업 시간표 2026.10.05~10.09` 같은 제목의 페이지가 하나씩 쌓입니다. 같은 주에 다시 불러오면 그 주 페이지를 새 내용으로 바꿉니다.
- 직접 입력한 일정도 함께 들어가고, 컴시간이 변경 수업으로 표시한 칸에는 🔄가 붙습니다.
- 노션 토큰은 OS 보안 저장소(macOS 키체인, Windows 자격 증명 관리자)에만 보관하고 설정 파일에는 쓰지 않습니다.
- 노션 보관이 실패해도 컴시간 갱신은 그대로 적용됩니다.

사용하려면 노션에서 API 토큰 방식의 연결을 만들고 보관할 페이지에 그 연결을 추가해야 합니다. 자세한 순서는 사용설명서의 “노션에 주간 시간표 보관”을 참고하세요. 켜지 않으면 기존과 똑같이 동작합니다.

## 설치

- Windows: `whattime.exe`
- macOS: `WhatTime-mac.dmg`

기존 설정을 유지한 채 업데이트할 수 있습니다.

# 지금 몇교시야 3.1.2

운영체제별 업데이트 안내를 개선한 패치입니다. Windows와 macOS 모두 배포합니다.

- Windows 전용 업데이트를 Mac에서 확인하거나, macOS 전용 업데이트를 Windows에서 확인할 때 설치 파일이 없다는 오류 대신 새 버전과 대상 운영체제를 안내합니다.
- 현재 운영체제에 해당하는 업데이트가 없으면 “업데이트 불필요”를 표시합니다. 해당 운영체제의 설치 파일이 있으면 기존처럼 업데이트할 수 있습니다.
- 3.1.1의 수업 알림창 초기화 개선도 포함합니다.

## 설치

- Windows: `whattime.exe`
- macOS: `WhatTime-mac.dmg`

기존 설정을 유지한 채 업데이트할 수 있습니다. 운영체제별 업데이트 안내는 3.1.2 설치 후 적용됩니다.
